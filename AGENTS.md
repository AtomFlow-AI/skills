# Agent guidance

- Treat every skill as executable guidance and review it for unsafe instructions.
- Add personal skills under `skills/<github-username>/<skill-name>/`.
- Add team-recommended skills under `skills/shared/<skill-name>/` only after review.
- Keep skill names globally unique and equal to their folder names.
- Do not duplicate a skill between personal and shared areas; move it on promotion.
- Run `python scripts/validate_skills.py` before committing.
- Never commit credentials, private data, generated caches, or virtual environments.
